✨ How In-Browser Dynamic Python Execution Works

📱 Native iOS & Mobile Support

Powered by Pyodide (Python compiled to WebAssembly), all Python code snippets, custom scratchpad experiments, and multi-library pipelines run directly inside Safari on iOS and Chrome on Android without needing any local server installation.

🌐 1-Click GitHub Pages Ready

This repository is 100% static-hostable. Push this repository to GitHub, enable GitHub Pages in your repository settings under Settings → Pages, and your interactive academy will be live worldwide instantly.

⚡ Hybrid Dual Execution Engine

If you run locally with python ml_academy_server.py, it seamlessly routes requests to high-speed native Python 3.14 on localhost:8765. When disconnected or hosted on GitHub, it automatically switches to Pyodide WebAssembly!
