Why Does Math Glue Letters Together?

Machine learning formulas look terrifying only because textbooks rarely explain how math glues letters together. Why does one book write ŷ = w₁x₁ + w₂x₂ + b while another writes f_θ(x) = θᵀx? They are the exact same equation in two different dialects.

w Single Weight

The Weight / Slope Multiplier

"How much does 1 unit of feature x swing the answer?" Think of an Uber meter: if w = $3/mile, driving 10 miles adds $30.

• w > 0: Increases output (more miles = higher fare)
• w < 0: Decreases output (older car = lower price)
• w = 0: Feature ignored (0 influence)
w₁ (wⱼ) Column ID Tag

Subscript = Column Name Tag

A tiny subscript is NOT math—you never multiply or square by it! In a table with multiple columns (x₁ = SqFt, x₂ = Beds), w₁ is Column 1's price tag and w₂ is Column 2's price tag.

ŷ = w₁x₁ ($150/sqft) + w₂x₂ ($25k/bed) + b (base land)
f_θ(x) Hypothesis / Model

Parameterized Prediction Function

In algebra, f(x) is static. In ML, the formula changes as the computer tunes its dials θ! The subscript θ reads: "The prediction function f using dial settings θ." Also written as h_θ(x) (Hypothesis).

f_θ(x) ≡ h_θ(x) ≡ ŷ (The Computer's Guess!)
θ Parameter Vector

Theta = All Dials Bundled

Academic math bundles the bias and all weights into one Greek vector θ = [θ₀, θ₁, θ₂...]ᵀ. Notice that θ₀ ≡ b (base fee) and θ₁ ≡ w₁ (weight 1).

θᵀx = θ₀(1) + θ₁x₁ + θ₂x₂ ≡ wᵀx + b

Mental Models

The Secret Habits of Math Notation

Mathematicians use these shorthand conventions daily without explaining them to beginners:

1. Invisible Multiplication: wx = w × x

Two letters touching with no symbol between them always mean multiply. Why no ×? Because × looks identical to the variable x!

2. Multiply First, Add Second: wx + b = (w × x) + b

You always compute the squished multiplication chunk wx first, and then add +b. Example: (150 × 10) + 500 = 2,000.

3. Subscript = Column ID Badge: x₁, x₂, w₁, w₂

A tiny number at the bottom right is NOT math—never multiply by it! When predicting house prices, w₁ is Column 1's weight ($/sqft) and w₂ is Column 2's weight ($/bed).

4. Parentheses at Top = Row Index: x⁽ⁱ⁾ vs x²

A number wrapped in parentheses at the top x⁽ⁱ⁾ indicates Row #i in your dataset. Without parentheses, x² means squared (x × x)!

5. Marks on Top: Real y vs. Guess ŷ vs. Mean ȳ

Bare y = ground truth on the receipt ($300k). Caret hat ŷ ("y-hat") = model's prediction ($285k). Flat bar ȳ ("y-bar") = arithmetic mean ($250k).

6. Subscript Greek θ: Parameterized Function f_θ(x) ≡ h_θ(x) ≡ ŷ

In algebra, f(x) is static. In ML, the function changes as the computer tunes its dials θ! The subscript θ reads: "Function f configured by parameters θ". Exactly equals the computer's guess ŷ.
