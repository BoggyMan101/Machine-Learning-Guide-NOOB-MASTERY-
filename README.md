# ML & LureLock Interactive Academies (v3.0.2)

An interactive, pedagogy-driven suite of learning academies covering Machine Learning statistical mechanics, anti-phishing cybersecurity modeling, and interactive visual formulas.

---

## 📦 What's Included

- **Web Academies**:
  - `index.html`: Unified portal launcher
  - `ml_interactive_academy.html`: Complete Machine Learning Interactive Academy with interactive step-by-step statistical calculations, formula breakdowns, and live visual studios.
  - `lurelock_interactive_academy.html`: LureLock Cybersecurity & Anti-Phishing Interactive Academy.
  - `machine_learning_formula_rosetta_stone.html`: Formula Rosetta Stone mapping notation, symbols, code equivalents, and interactive calculation sandboxes.
- **Prebuilt Binaries**:
  - `ML_LureLock_Academies_v8.2.apk`: Standalone release-signed Android application with offline reading-progress persistence.
  - `ML_LureLock_Academies_v8.2_Desktop.exe`: Standalone Windows Desktop application with embedded web engine and progress state preservation.

---

## 🚀 Getting Started

### 1. Web Version
Open `index.html` in any modern web browser (Edge, Chrome, Firefox, Safari) or host with any static file server:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.

### 2. Android (APK)
Transfer `ML_LureLock_Academies_v8.2.apk` to an Android device (Android 7.0+ / API 24+) and install. Ensure **"Install unknown apps"** is enabled for your file manager.

### 3. Windows Desktop
Double-click `ML_LureLock_Academies_v8.2_Desktop.exe` to launch directly. No installation or external dependencies required.
